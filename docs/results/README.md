# Сравнение четырёх конфигураций

Статус: завершён с ограничениями. Финальный срез сформирован из последних чекпоинтов.

| Конфигурация | Ответы | Ошибки | Неполные обязательные оценки | Dev recall@5 | Test recall@5 | Gen score |
|---|---:|---:|---:|---:|---:|---:|
| stand_hybrid_512 | 250/250 | 0 | 11 | 82,43% | 82,45% | 0,771 |
| stand_hybrid_qbm25_512 | 250/250 | 0 | 22 | 79,31% | 81,03% | 0,762 |
| stand_dense_1024 | 250/250 | 1 | 50 | 77,92% | 81,77% | 0,772 |
| stand_dense_512 | 250/250 | 0 | 47 | 74,57% | 76,50% | 0,748 |

Автоматический победитель не выбран из-за разного охвата LLM-оценивания.
Рабочая рекомендация — `stand_hybrid_512`: лучший retrieval, максимальная
faithfulness, минимальное число неполных оценок и меньший расход токенов по
сравнению с `stand_dense_1024`.

Полные агрегированные метрики находятся в `retrieval-summary.csv`,
`retrieval-by-question-type.csv` и `generation-summary.csv`. Пропуски не
заменены нулями. Сохранённые ответы, контексты и usage при восстановительных
проходах не изменялись.
